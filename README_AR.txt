# تطبيق متتبع تحدي التداول | Trading Challenge Tracker

تطبيق تداول شخصي متكامل لإدارة ومتابعة تحدي الـ 150 صفقة.

## الميزات الرئيسية
- 150 محطة تداول مرتبطة تلقائياً بكل صفقة مسجلة.
- حسابات مالية دقيقة بوحدات السنت (Cents) لمنع أي أخطاء تقريب ثنائية.
- سجل صفقات متكامل مع خيارات الفلترة (الكل، الربح، الخسارة، مع صور).
- إمكانية إرفاق صور للشارت وتحليلات الصفقات واستعراضها بحجم كامل.
- تقرير PDF / HTML احترافي باللغة العربية متوافق مع اتجاه RTL وخالٍ من الصور بحسب المواصفات، وقابل للمشاركة عبر نظام Android Sharesheet أو طباعته كـ PDF.
- إمكانية حفظ رأس المال واسم المتداول والهدف النهائي مع الحفاظ على البيانات عند إغلاق التطبيق.
- خريطة المحطات التفاعلية تعرض حالة كل صفقة من الـ 150 صفقة.
- إدارة التحدي: إعادة التحدي، وبدء تحدٍ جديد برأس مال مخصص مع نوافذ تأكيد لحماية البيانات.

## هيكل المشروع
- Kotlin + Jetpack Compose + Room Database + ViewModel + Coroutines لنظام Android الأصلي.
- Vite + React + TypeScript + Tailwind CSS للواجهة التفاعلية السريعة على الويب والـ PWA.
